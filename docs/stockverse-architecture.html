Concurrency Control
Optimistic Locking Pattern (@Version)
Prevents the classic Lost Update race condition without thread-blocking pessimistic locks. Under heavy concurrent trade execution, threads do not hold database row locks (`SELECT FOR UPDATE`), eliminating thread pool exhaustion and deadlocks. 
// Entity version check in SQL
UPDATE app_users 
SET cash_balance = ?, version = version + 1 
WHERE id = ? AND version = ?;

// If affected rows == 0:
// Throws ObjectOptimisticLockingFailureException
// Rollback TX -> Map to HTTP 409 Conflict
Takeaway: High-throughput financial ledgers prefer OCC over pessimistic locking: failed attempts trigger clean rollbacks and client retry prompts rather than locking table rows.
Data Caching
Event-Driven Redis Cache Invalidation
Gemini 1.5 Flash portfolio evaluations take 1.2–2.5s and consume billable quotas. Redis caches diagnostics under portfolioAnalysis::<userId> with a 15-minute TTL. Any BUY or SELL trade immediately purges the key via @CacheEvict. 
// Retrieval with Redis Cache
@Cacheable(value = "portfolioAnalysis", key = "#userId")
public PortfolioAnalysisDto analyzePortfolio(Long userId) { ... }

// Immediate Write-Through Invalidation
@Transactional
@CacheEvict(value = "portfolioAnalysis", key = "#userId")
public TradeResponse executeTrade(...) { ... }
Takeaway: Sub-35ms read delivery with guaranteed write-through freshness, backed by a fail-open CacheErrorHandler if Redis is down.
LLM Reliability
Structured JSON Schema Enforcement
Raw LLM text and markdown fences (```json) break frontend charts. StockVerse pairs LangChain4j with Gemini 1.5 Flash using ResponseFormat.JSON and temperature 0.2 to guarantee schema compliance for portfolio scores (0-100) and risk metrics. 
GoogleAiGeminiChatModel.builder()
  .apiKey(geminiKey)
  .modelName("gemini-1.5-flash")
  .temperature(0.2) // Deterministic output
  .responseFormat(ResponseFormat.JSON)
  .timeout(Duration.ofSeconds(60))
  .build();
Takeaway: Defense-in-depth: Includes zero-holding fast return and algorithmic rule-based fallback if the AI API encounters rate limits.

User.java — Optimistic Locking (@Version) 
@Entity
@Table(name = "app_users")
@Getter @Setter @Builder
public class User {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false, unique = true)
    private String email;

    @Column(nullable = false, precision = 19, scale = 4)
    @Builder.Default
    private BigDecimal cashBalance = new BigDecimal("100000.0000");

    @Version
    @Column(name = "version")
    @Builder.Default
    private Long version = 0L;

    // Defense-in-depth against null version unboxing
    @PostLoad @PrePersist @PreUpdate
    private void ensureVersionNotNull() {
        if (this.version == null) this.version = 0L;
    }
}
CacheConfig.java — Fail-Open Redis 
@Configuration
@EnableCaching
@Slf4j
public class CacheConfig implements CachingConfigurer {

    @Bean
    public RedisCacheManager cacheManager(RedisConnectionFactory factory) {
        RedisCacheConfiguration config = RedisCacheConfiguration.defaultCacheConfig()
            .entryTtl(Duration.ofMinutes(15))
            .disableCachingNullValues()
            .serializeValuesWith(SerializationPair.fromSerializer(RedisSerializer.json()));

        return RedisCacheManager.builder(factory).cacheDefaults(config).build();
    }

    @Override
    public CacheErrorHandler errorHandler() {
        return new CacheErrorHandler() {
            @Override
            public void handleCacheGetError(RuntimeException ex, Cache c, Object k) {
                log.warn("Redis GET failed for key [{}]. Falling back.", k);
            }
            @Override
            public void handleCacheEvictError(RuntimeException ex, Cache c, Object k) {
                log.warn("Redis EVICT failed for key [{}]. Continuing.", k);
            }
        };
    }
}
PortfolioAiService.java — Gemini JSON Mode 
@Service
@RequiredArgsConstructor
@Slf4j
public class PortfolioAiService {
    private final ChatLanguageModel chatModel;
    private final PortfolioPositionRepository positionRepo;
    private final ObjectMapper mapper;

    @Cacheable(value = "portfolioAnalysis", key = "#userId")
    public PortfolioAnalysisDto analyzePortfolio(Long userId) {
        List<PortfolioPosition> positions = positionRepo.findByUserId(userId);
        if (positions.isEmpty()) return getDefaultStarterAssessment();

        try {
            String rawJson = chatModel.generate(buildStructuredPrompt(positions));
            String cleaned = rawJson.replaceAll("```json\\s*", "").replaceAll("```\\s*", "").trim();
            return mapper.readValue(cleaned, PortfolioAnalysisDto.class);
        } catch (Exception e) {
            log.error("AI analysis failed: {}. Falling back.", e.getMessage());
            return buildFallbackAssessment(positions);
        }
    }
}
JwtTokenFilter.java — Stateless Security 
@Component
@RequiredArgsConstructor
public class JwtTokenFilter extends OncePerRequestFilter {
    private final JwtService jwtService;
    private final CustomUserDetailsService userDetailsService;

    @Override
    protected void doFilterInternal(HttpServletRequest req, HttpServletResponse res, FilterChain chain)
            throws ServletException, IOException {
        String authHeader = req.getHeader(HttpHeaders.AUTHORIZATION);
        if (authHeader == null || !authHeader.startsWith("Bearer ")) {
            chain.doFilter(req, res);
            return;
        }

        String token = authHeader.substring(7);
        if (jwtService.isTokenValid(token)) {
            UserDetails user = userDetailsService.loadUserByUsername(jwtService.extractUsername(token));
            UsernamePasswordAuthenticationToken auth = 
                new UsernamePasswordAuthenticationToken(user, null, user.getAuthorities());
            auth.setDetails(new WebAuthenticationDetailsSource().buildDetails(req));
            SecurityContextHolder.getContext().setAuthentication(auth);
        }
        chain.doFilter(req, res);
    }
}

06 — Debug & Troubleshooting

Engineering Gotchas & Incident Response

Known production failure modes, concurrency race conditions, and mitigation playbooks.

Gotcha 1: Concurrency Collisions Throwing 500 Instead of 409
Symptom: Rapid double-clicks throw ObjectOptimisticLockingFailureException, showing an internal error.
Fix: Catch optimistic lock exceptions in TradeService, wrap in TradeConflictException, and map via @RestControllerAdvice to HTTP 409 Conflict so the UI can prompt the user to retry.
Gotcha 2: Redis Connection Partition Crashing Trades
Symptom: If Redis restarts or drops connections, `@CacheEvict` in the trade method crashes transactions.
Fix: Implement CachingConfigurer.errorHandler() in CacheConfig.java. Log eviction errors as warnings so PostgreSQL commits succeed even if Redis is unreachable.
Gotcha 3: Infinite JSON Recursion on JPA Fetch
Symptom: Fetching positions throws Document nesting depth (501) exceeds the maximum allowed.
Fix: Add @JsonIgnore to bidirectional parent entity references in child entities (e.g. @ManyToOne @JsonIgnore private User user; in PortfolioPosition.java).
Gotcha 4: Hibernate NullPointerException inside Versioning.increment
Symptom: Pre-existing database rows with SQL NULL in the version column trigger unboxing NPEs.
Fix: Add @Builder.Default private Long version = 0L; along with JPA lifecycle callbacks (@PostLoad @PrePersist @PreUpdate) ensuring version != null.
